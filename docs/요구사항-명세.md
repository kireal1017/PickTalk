# Windows 텍스트 선택 번역기 명세

- 버전: 0.2
- 상태: 초안
- 대상: Windows 10/11 x64

## 1. 목적

다른 앱에서 텍스트를 드래그해 선택한 뒤 `Ctrl` 키를 누르면, 번역 결과를 마우스 커서 옆의 작은 팝업으로 보여주는 Windows 데스크톱 유틸리티를 만든다. 사용자는 설정에서 번역 엔진을 Google 번역 또는 로컬 AI 번역 중 하나로 선택한다.

## 2. 핵심 사용자 흐름

1. 사용자가 앱 바깥의 문서, 웹페이지 등에서 텍스트를 드래그해 선택한다.
2. 선택 영역을 유지한 채 `Ctrl` 키를 누른다.
3. 앱이 선택된 텍스트를 가져와 현재 설정된 번역 엔진으로 번역한다.
4. 마우스 커서 가까이에 작은 팝업을 표시하고 번역 결과를 보여준다.
5. 사용자는 팝업을 닫거나 결과를 복사한다.

## 3. 기능 요구사항

### 3.1 선택 텍스트 감지

- 전역 입력 감지는 사용자가 선택을 마친 뒤 `Ctrl` 키를 눌렀을 때 번역 동작을 시작한다.
- 좌우 `Ctrl` 키를 지원한다.
- 선택 텍스트는 클립보드 복사 단축키를 이용해 읽는 방식을 우선 검토한다. 기존 클립보드 내용은 가능한 한 복원한다.
- 텍스트를 가져오지 못하거나 선택 내용이 비어 있으면 오류 팝업 대신 조용히 무시하거나 간단한 안내를 표시한다.
- 번역 중 중복 입력으로 동일 요청이 여러 번 실행되지 않도록 한다.

### 3.2 번역 엔진 설정

설정 화면에서 다음 두 엔진 중 하나를 선택한다.

- **Google 번역**: Google 번역 웹 번역 경로를 사용한다. 네트워크 연결이 필요하며 선택 텍스트가 Google에 전송됨을 설정 화면에 알린다.
- **로컬 AI**: 사용자의 로컬 Ollama 서버를 사용한다. 기본 주소는 `http://127.0.0.1:11434`이며 모델 이름과 서버 주소는 설정에서 확인·수정할 수 있게 한다. 기본 모델은 `qwen3.5:0.8b`로 한다.

선택된 엔진만 번역에 사용한다. 엔진 장애 시 다른 엔진으로 자동 전환하지 않는다. 로컬 AI 오류는 Ollama 연결 또는 모델 설정 안내로 표시하고, Google 번역 오류는 네트워크/서비스 오류로 표시한다.

### 3.3 번역 언어

- 원문 언어는 자동 감지를 기본값으로 한다.
- 번역 대상 언어는 한국어를 기본값으로 한다.
- 번역 대상 언어를 설정에서 바꿀 수 있도록 한다.

### 3.4 결과 팝업

- 번역 결과를 마우스 커서 옆의 작고 눈에 띄지 않는 팝업으로 표시한다.
- 화면 가장자리에서는 팝업이 화면 밖으로 나가지 않도록 위치를 보정한다.
- 팝업에 번역 결과와 복사 버튼을 제공한다.
- `Esc` 키 또는 팝업 바깥 클릭으로 닫을 수 있다.
- 번역 중에는 진행 상태를 표시하고 실패 시 짧은 오류 안내를 표시한다.

### 3.5 앱 동작

- 앱은 시스템 트레이에서 실행·종료할 수 있다.
- 설정 창에서 번역 엔진, Ollama 주소/모델, 대상 언어를 변경할 수 있다.
- Windows 시작 시 자동 실행과 번역 기록 저장은 기본적으로 끈다.

## 4. 개인정보 및 보안

- 로컬 AI 모드에서는 번역 요청을 설정된 로컬 Ollama 주소로만 보낸다.
- Google 번역 모드에서는 선택 텍스트가 Google 번역 서비스로 전송될 수 있음을 명확히 알린다.
- 텔레메트리, 분석, 광고, 별도 사전/보강 API 전송을 넣지 않는다.
- 선택 텍스트 및 번역 결과를 로그나 기록에 저장하지 않는다.
- 자동 시작, 클립보드 접근, 네트워크 사용 여부를 사용자가 확인할 수 있게 문서화한다.
- 설정은 로컬에 저장하며 비밀 정보가 필요하지 않은 경우 API 키를 요구하지 않는다.

## 5. 이번 버전 범위

포함:

- Windows용 트레이 앱
- 선택 텍스트 감지 후 `Ctrl` 입력으로 번역 실행
- 커서 옆 결과 팝업
- Google 번역 / 로컬 Ollama 번역 선택 설정
- 번역 결과 복사 및 기본 오류 안내

제외:

- OCR 및 이미지 번역
- 문서 전체/파일 일괄 번역
- 번역 결과를 원문 위치에 자동 삽입
- 번역 기록/클라우드 동기화
- 자동 대체 번역 엔진
- macOS/Linux 지원

## 6. 완료 기준

- 앱이 실행 중일 때 지원되는 Windows 앱에서 텍스트를 선택하고 `Ctrl`을 누르면 번역 요청이 시작된다.
- 결과 팝업이 마우스 커서 근처에 표시되고 화면 경계 안에 머문다.
- 설정에서 Google 번역과 로컬 AI를 전환할 수 있고, 재실행 후에도 선택이 유지된다.
- 로컬 AI 모드에서 Ollama 연결 실패 시 Google로 자동 전송되지 않는다.
- Google 모드에서는 외부 전송 사실이 사용자에게 고지된다.
- 복사, 닫기, 오류 표시가 동작한다.
- 번역 텍스트가 앱 로그나 번역 기록에 저장되지 않는다.
