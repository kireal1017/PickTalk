# PickTalk

텍스트를 드래그해 선택하고 `Ctrl` 키를 누르면, 마우스 커서 옆에 번역 결과를 보여주는 Windows 번역 도우미입니다.

## 현재 상태

프로젝트는 개발 준비 단계입니다. 앱 기능은 아직 구현되지 않았습니다. 현재 저장소에는 요구사항 명세와 프로젝트 README가 있습니다.

## 계획 중인 기능

- 선택한 텍스트만 가져와 번역
- 선택을 마친 뒤 `Ctrl` 키를 누르는 순간 번역 시작
- 커서 가까이에 번역 결과 팝업 표시
- 설정에서 로컬 Ollama와 Google 번역 서비스 중 선택
- 번역 결과 복사, 팝업 닫기, 시스템 트레이 상주
- 번역 기록과 텍스트 로그는 저장하지 않음

선택 텍스트를 읽는 방법은 메모장, 브라우저, 문서 편집기 등에서 개발 후 호환성을 확인할 예정입니다. 선택 내용을 가져올 수 없는 경우 전체 페이지나 문서로 범위를 넓히지 않습니다.

## 기술 방향

- C# / WPF
- .NET 10 LTS
- Windows 10/11 x64
- 로컬 번역: Ollama (`http://127.0.0.1:11434`), 기본 모델 후보 `qwen3.5:0.8b`
- 온라인 번역: Google 번역 API 방식은 확정 전

온라인 번역은 외부 서비스로 선택 텍스트를 전송할 수 있으므로, 실제 API와 비용 정책을 결정한 뒤 명세에 반영합니다. 번역 엔진 장애 시 다른 엔진으로 자동 전환하지 않는 것을 기본 원칙으로 합니다.

## 개인정보 원칙

- 로컬 AI 모드의 번역 요청은 설정된 로컬 Ollama 서버로 보냅니다.
- 온라인 번역 모드에서는 선택 텍스트가 해당 번역 서비스로 전송될 수 있음을 알립니다.
- 선택 텍스트와 결과를 로그나 번역 기록에 저장하지 않습니다.
- 텔레메트리, 광고, 별도 사전·보강 서비스 전송을 추가하지 않습니다.
- 자동 실행과 번역 기록 저장은 기본적으로 끕니다.

## 개발 환경

앱 개발에는 Windows x64용 .NET 10 SDK와 WPF 프로젝트 템플릿이 필요합니다. Visual Studio IDE 전체 설치는 필수가 아닙니다.

앱 구현이 시작되면 이 문서에 빌드 및 실행 방법을 추가하겠습니다.
